# 🛒 Redux Shop

A simple shopping cart application built with **React** and **Redux**. This project demonstrates the use of Redux for state management in a real-world e-commerce scenario.

## 🚀 Features

- Product listing with details
- Add/Remove items from the cart
- View cart summary
- Dynamic state updates using Redux
- Clean and modular code structure

## 🛠️ Tech Stack

- **React**
- **Redux**
- **JavaScript**
- **HTML5 & CSS3**
